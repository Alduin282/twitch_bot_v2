# Twitch Bot
Модульный Twitch-бот с AI и плагинной архитектурой.
Реагирует на события чата, задаёт вопросы, отвечает пользователям и логирует активность.

## Как воспользоваться 
1. Стяните репозиторий локально (python 3.13.9)
2. стяните все библиотеки через pip install -r requirements.txt
3. Добавьте файл .env и внесите туда 2 пременные - TWITCH_TOKEN_AOTH и TWITCH_SECRET_KEY. Токен и секрет бота соответсвенно. 
4. Откройте main
5. Добавьте плагины и настройте параметры
6. запустите main
*ai модули требует локально запущенного ollama (скачать можно [тут](https://ollama.com/download)), а также скачанную ai модель (по дефуолту - aya:8b)

## Имеющиеся плагины (фукнционал бота)
### AIPersonaPlugin
Плагин для динамического управления персонажем ИИ-бота через чат Twitch.
Позволяет управлять поведением бота, изменяя его "личность".
Обрабатывает команды вида:
1. `!persona` (напишет текущд личность в чат),
2. `!persona random`(сам себе сгенерирует личность),
3. `!persona reset`(вернет дефолтную личность).
### AIAskPlugin
Плагин для Twitch-бота, позволяющий задавать вопросы ИИ через команду !ask.

Реализует:
    - Обработку команды !ask <вопрос>
    - Ограничение частоты использования (cooldown) по каналу
    - Отправку краткого ответа от ИИ в чат

Пример использования:
    !ask как дела?
    !ask расскажи шутку
### AIQuestionSpamPlugin
Плагин для автоматической генерации и отправки вопросов стримеру от имени бота.

Плагин активируется при событии READY и запускает бесконечный цикл:
    - Регулярно (с интервалом DurationRange ) генерирует вопрос к стримеру. *можно задать случайный интервал , к примеру от 120 до 130 секунд
    - Вопрос основан на контексте стрима: название, игра, теги.
    - Отправляет вопрос в каждый из подключённых каналов.

Используется для поддержания активности в чате во время стрима.
Пример:
    Бот отправляет: «Расскажи, как ты пришёл к игре Dota 2?»
### ConsoleChatBotPlugin
Плагин для отправки сообщений в чат Twitch через консоль.

Позволяет разработчику или администратору вводить сообщения в терминал,
и бот отправляет их в указанные или все подключённые каналы.

Используется для:
    - Отладки
    - Ручного управления ботом
    - Быстрой рассылки уведомлений
###LaughReactionBotPlugin
Плагин-реакция на смех в чате Twitch.

Автоматически отвечает на сообщения, начинающиеся с триггеров смеха
(например, LOL, ахах, LUL), отправляя случайную реплику-смех от имени бота.

Работает с учётом кулдауна, чтобы избежать спама.
Пример:
    Зритель: LOL
    Бот: АХХАХАХАХА
Используется для создания иллюзии актива в чате.
### LogLaughBurstBotPlugin
Плагин для логирования "всплесков смеха" в Twitch-чатах.

Отслеживает частые упоминания смеха (например, ахаа, lul, хаха) в последних сообщениях.
Если за заданное окно сообщений таких упоминаний достаточно — записывает событие в файл лога.

Используется для анализа пиковых моментов в стриме (например, самые смешные сцены).

Пример записи в лог: pudge_live LAUGH-BURST at 2025-04-05 15:30:45+00:00 (0:12:10)
### LogStartBotPlugin
Просто логирует успешное подключение в консоль 
### PeriodicSpamBotPlugin
Плагин для периодической отправки сообщений в подключённые Twitch-каналы.

Отправляется одно из заданных сообщений с регулярными интервалами.
Интервал может быть случайным в указанных пределах — для более "человеческого" поведения.

Используется для:
    - Регулярного напоминания о стриме (подписки, донаты).
    - Ротации рекламных сообщений.
    - Поддержания активности в чате.
Пример:
    [00:12:30] Бот: Не забудь подписаться! ❤️
### PyramidBotPlugin
Плагин для построения текстовой пирамиды в чате Twitch по команде.

Поддерживает команду:
    !pyramid <высота> [смайл]

Где:
- **высота** — число от 2 до 10.
- **смайл** (опционально) — смайл или текст, из которого будет построена пирамида. Если не указан, используется стандартный (LUL).

Бот отвечает последовательностью сообщений, создающих визуальный эффект пирамиды.

Примеры:
1. `!pyramid 3` (дефолтный смайл)
    → LUL
    → LUL LUL
    → LUL LUL LUL
    → LUL LUL
    → LUL

2. `!pyramid 2 KEK` (кастомный смайл)
    → KEK
    → KEK KEK
    → KEK

3. `!pyramid 2 KEK CHO` (игнорирует лишние аргументы)
    → KEK
    → KEK KEK
    → KEK

Используется для развлечения зрителей и вовлечения в чат.
### ReactionBotPlugin
Плагин реакций на сообщения в чате Twitch по правилам.

Позволяет боту автоматически отвечать, если сообщение содержит определённые триггеры.
Ответ зависит от настроенной вероятности, задержки, кулдауна и других параметров.

Используется для:
    - Автоматических реплик на ключевые слова (например, "спасибо" → "обращайся!").
    - Поддержания живой атмосферы.
    - Персонализации поведения бота.

Пример:
    Зритель: спасибо за клип
    Бот: 🫶 Всегда рад!
